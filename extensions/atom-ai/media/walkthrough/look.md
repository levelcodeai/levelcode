### Make it feel like home

Atom++ keeps the Atom warmth and the Notepad++ power:

- **Signature themes** — One Dark / One Light, on by default
- **Keymap presets** — Atom, Notepad++, or Sublime, so your muscle memory just works
- **Notepad++ power-editing** — macros, column edit, line ops (sort / dedup / case), big-file mode, encoding & EOL toggles
- **Hackable** — a user init script, a package generator with live hot-reload, and your own keybindings

Pick a theme and a keymap to start — change them anytime.
